## Projects

### [LeadFlow](https://github.com/milovenn/leadflow)

Production-style lead intake automation built with n8n, Google Sheets and Discord.

Validates incoming leads, detects duplicates, calculates priority, routes notifications and logs execution outcomes.

### [API Data Pipeline](https://github.com/milovenn/api-data-pipeline)

Production-style data pipeline built with n8n, REST APIs and Google Sheets.

Fetches paginated API data, normalizes records, removes sensitive fields using an allowlist, deduplicates the dataset and synchronizes the cleaned output to Google Sheets.

**Key features:** automatic pagination, data cleaning, PII filtering, deduplication, Google Sheets upsert, retry handling and scheduled execution.
